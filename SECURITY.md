# Security policy

The latest stable release is supported. These static prototypes use sample data and do not provide authentication, server storage, or a notes backend. Do not enter secrets or sensitive personal data.

Report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/falconrapid19925/argon4test/security/advisories/new). Include affected files/versions, impact, and reproduction steps. Please avoid public issues containing an exploit before maintainers can assess it. Maintainers review reports as available; no response-time SLA is promised.

Development dependencies are locked and audited in CI. Dependabot checks weekly, Actions use commit pins, and CodeQL scans first-party code. Third-party assets retain upstream licenses; see [the attribution inventory](docs/THIRD_PARTY.md).
