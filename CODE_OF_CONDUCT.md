# Code of conduct

Treat participants with respect. Be constructive and specific when discussing code and design; welcome contributors of different backgrounds and experience levels.

Harassment, discriminatory language, threats, doxxing, and sexualized attention are not acceptable. Respect others' privacy and stop conduct when asked.

Report concerns privately through the repository owner's [GitHub profile](https://github.com/falconrapid19925) using any contact method they publish. Do not post private reports in public issues. If no private contact is available, use GitHub's reporting tools for abuse. Maintainers may remove content, close discussions, or restrict participation to keep this project welcoming. Maintainers should explain moderation decisions where doing so respects privacy.
